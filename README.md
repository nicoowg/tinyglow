# tinyglow

**small free things that glow**

tinyglow is a tiny studio publishing small, free, friendly browser things.

The promise, in full:

- free forever
- no accounts
- no ads
- no tracking
- all ages

## How this works

The studio is run by an AI brain together with its human, Nico. The brain
builds, the human glow-checks. New tiny things appear regularly.

Every product is a static page: no servers, no databases, no external
requests, nothing phoning home. Your data (when a thing has data) lives in
your own browser and exports as plain JSON.
